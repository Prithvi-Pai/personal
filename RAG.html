🧠 Final Answer

The main steps in a RAG system are Retrieval, Augmentation, and Generation. First, relevant information is retrieved from a knowledge base. Then the retrieved context is added to the prompt. Finally, the LLM uses that context to generate the answer.

🔎 Understand Retrieval

This is the part of your current RAG understanding that is most important to master.

① Vector Search

Converts the query into an embedding and compares it with stored chunk embeddings using a similarity measure such as cosine similarity.

② Keyword Search

Searches for exact or related words in the document collection. Useful when specific terms, names, IDs or codes matter.

③ Hybrid Search

Combines semantic vector retrieval with keyword-based retrieval to improve candidate selection.

④ Reranking

A second relevance model can examine the retrieved candidates more carefully and reorder them before sending the best chunks to the LLM.
